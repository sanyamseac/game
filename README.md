To run the app for first time, use following commands:
```
git clone https://github.com/sanyamseac/game.git
cd game
cp .env.example .env
npm i
npm run db:push [You might use another shell session simultaneously]
npm run dev
```
Follow the link generated by vite. The changes will be reflected live.

To run the app later on:
> npm run dev

To run database studio to give admin roles or manage other data
> npm run db:studio

To build the app for production:
> npm run build

To preview build version:
> npm run preview

To host it:
> Change the origin variable in .env file to host url before building and run node build after building
